# Git Conventions

Commit-Format: `<type>: <kurze Beschreibung>` in Kleinbuchstaben, ohne abschließenden Punkt.

| Typ | Verwendung |
|------|-----|
| `feat` | neues Feature |
| `fix` | Fehlerbehebung |
| `refactor` | Umstrukturierung ohne Verhaltensänderung |
| `style` | Formatierung, keine Auswirkung auf die Logik |
| `docs` | Dokumentation |
| `chore` | Build, Abhängigkeiten, Konfiguration |
